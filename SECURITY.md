# Política de Segurança

A segurança e a privacidade são partes importantes do Moon Browser. Como o projeto ainda está em fase experimental, relatos responsáveis ajudam a corrigir problemas antes que eles afetem mais usuários.

## Versões suportadas

No momento, somente a linha de desenvolvimento mais recente recebe correções ativas de segurança. Builds antigas e demos públicas podem não receber backports.

## Como reportar uma vulnerabilidade

Não publique detalhes exploráveis de uma vulnerabilidade em uma issue pública.

Ao relatar um problema de segurança, inclua quando possível:

- versão ou commit afetado;
- sistema operacional;
- passos mínimos para reprodução;
- impacto observado;
- logs ou capturas sem dados sensíveis;
- sugestão de mitigação, se houver.

Use um canal privado do mantenedor do projeto para compartilhar detalhes sensíveis. Se ainda não houver um canal dedicado configurado no GitHub, entre em contato pelo e-mail do projeto indicado no repositório.

## Escopo prioritário

Relatos envolvendo os seguintes pontos têm prioridade:

- exposição de credenciais ou dados locais;
- execução de código não autorizada;
- bypass de isolamento entre perfis, janelas privadas ou contextos;
- manipulação insegura de downloads, permissões ou conteúdo remoto;
- falhas que permitam acesso indevido a histórico, notas, memória ou arquivos do usuário.

## Divulgação responsável

Pedimos tempo razoável para investigar e corrigir a falha antes de qualquer divulgação pública detalhada. Quando apropriado, o crédito ao pesquisador pode ser incluído na correção ou release correspondente.

## Limites atuais

O Moon Browser é software experimental e não deve ser usado como único navegador para dados críticos ou ambientes que exijam garantias formais de segurança. Recursos marcados como experimentais ou fundação técnica podem ter riscos e limitações adicionais.
