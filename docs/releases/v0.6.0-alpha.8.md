# v0.6.0-alpha.8 — candidata, não publicada

Este documento descreve o código na branch de auditoria. Não há downloads alpha.8 nem promessa de atualização segura para usuários até os gates de assinatura e homologação passarem.

## Mudanças

- Política de segurança uniforme em janelas, popups e `WebContentsView`, bloqueio de webview/redirect privilegiado e cinco fuses verificados no AppImage.
- Atualizador nativo condicionado a build de release assinado. Windows exige Authenticode e publisher; AppImage exige assinatura Ed25519 verificada contra chave pública embutida. O workflow prepara GPG, checksums e SBOM CycloneDX.
- Limpeza mais ampla de sessão privada no fechamento nativo, com E2E de dados de site e zoom.
- Regras Ghostery fixadas em commit; benchmark de 10/30 abas e documentação de rede, riscos e compatibilidade atualizados.

## Validação local

- `npm run typecheck`, `npm run lint` e `npm run test:coverage`: 341 unitários/integração, 76,38% das linhas e 57,44% dos ramos dos módulos incluídos; armazenamento Electron passou em gate separado (37 testes).
- `MOON_HEADLESS=1 npm run test:e2e`: 32 passaram, 3 sondas externas ignoradas.
- `npm run verify:fuses` após build AppImage Linux; build de release com chave Ed25519 temporária, chave pública presente no ASAR, assinatura gerada e verificada.
- `MOON_HEADLESS=1 npm run measure:resources`: 10 abas 1560 MiB; 30 abas 3754 MiB; CPU em repouso amostrada em 1,3% para ambos. Fixture local simples, host de desenvolvimento, uma amostra; não representa sites reais nem comparação antes/depois.
- `npm audit --audit-level=high` passou com 11 avisos moderate de dependências transitivas de desenvolvimento/build; `npm audit --omit=dev --audit-level=moderate` não encontrou avisos de produção. SBOM CycloneDX 1.5 local contém 41 componentes.

## Bloqueios de publicação

Certificado Authenticode, chaves GPG/Ed25519 de produção, assinatura/upgrade Windows, pacote Linux completo, rollback testado, macOS/ARM, criptografia de dados locais, DRM e sites prioritários ainda não foram homologados.
