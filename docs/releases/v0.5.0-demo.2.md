# Moon Browser 0.5.0 Demo 2

> Uma atualização de produto focada em personalização profunda, isolamento local e uma distribuição desktop verificável.

![Moon Browser — Home](https://raw.githubusercontent.com/heitgh/Moon-browser/v0.5.0-demo.2/assets/screenshots/personalization-v4-home-final.png)

## Destaques

- **Personalization Studio V4:** modos Simples e Avançado, busca por intenção, preview ao vivo, aplicar/cancelar e undo/redo transacionais.
- **Biblioteca visual de temas:** temas Moon, locais e `.moontheme` no mesmo catálogo, com busca, filtros, favoritos, thumbnails, seleção por áreas e rollback de versões.
- **Home editável:** mover e redimensionar widgets com mouse, touch ou teclado, presets distintos e portabilidade `.moonhome` validada.
- **Editor de ícones:** overrides semânticos, packs SVG sanitizados, preview e fallback nativo.
- **Wallpapers seguros:** PNG/JPEG, GIF e WebP animados com validação, poster estático, pausa por visibilidade, energia e movimento reduzido.
- **Perfis locais:** SQLite, sessões Chromium, preferências e downloads isolados; convidado temporário e janela privada não restaurável.
- **Fundação E2EE:** engine offline-first e contratos de sync testados, ainda desativados em produção até existir provider oficial.

## Downloads

### Windows 10/11 x64

- **Instalador:** [Moon-Browser-Windows-x64-Setup.exe](https://github.com/heitgh/Moon-browser/releases/download/v0.5.0-demo.2/Moon-Browser-Windows-x64-Setup.exe)
- **Portátil:** [Moon-Browser-Windows-x64-Portable.exe](https://github.com/heitgh/Moon-browser/releases/download/v0.5.0-demo.2/Moon-Browser-Windows-x64-Portable.exe)
- **Checksums:** [SHA256SUMS-windows.txt](https://github.com/heitgh/Moon-browser/releases/download/v0.5.0-demo.2/SHA256SUMS-windows.txt)

Os executáveis ainda não possuem assinatura comercial. O Windows SmartScreen pode mostrar um aviso; confira `SHA256SUMS-windows.txt` antes de executar.

### Linux x64

- **Universal:** [Moon-Browser-Linux-x64.AppImage](https://github.com/heitgh/Moon-browser/releases/download/v0.5.0-demo.2/Moon-Browser-Linux-x64.AppImage)
- **Debian, Ubuntu, Linux Mint e derivados:** [Moon-Browser-Linux-x64.deb](https://github.com/heitgh/Moon-browser/releases/download/v0.5.0-demo.2/Moon-Browser-Linux-x64.deb)
- **Fedora, RHEL e openSUSE:** [Moon-Browser-Linux-x64.rpm](https://github.com/heitgh/Moon-browser/releases/download/v0.5.0-demo.2/Moon-Browser-Linux-x64.rpm)
- **Arch Linux, Manjaro e EndeavourOS:** [Moon-Browser-Linux-x64.pacman](https://github.com/heitgh/Moon-browser/releases/download/v0.5.0-demo.2/Moon-Browser-Linux-x64.pacman)
- **Checksums:** [SHA256SUMS-linux.txt](https://github.com/heitgh/Moon-browser/releases/download/v0.5.0-demo.2/SHA256SUMS-linux.txt)

Verifique os arquivos com:

```bash
sha256sum --check SHA256SUMS-linux.txt
```

Exemplos de instalação:

```bash
# AppImage
chmod +x Moon-Browser-Linux-x64.AppImage
./Moon-Browser-Linux-x64.AppImage

# Debian / Ubuntu
sudo apt install ./Moon-Browser-Linux-x64.deb

# Fedora / RHEL
sudo dnf install ./Moon-Browser-Linux-x64.rpm

# Arch / Manjaro
sudo pacman -U ./Moon-Browser-Linux-x64.pacman
```

## Estado honesto da Demo

Esta ainda é uma versão de testes e não deve ser o único navegador usado para dados críticos. Moon Intelligence continua desativada até possuir provider, consentimento, budgets, memória controlável e segurança completos. Sync remoto, cofre persistente e Moon Hub também permanecem bloqueados até existirem serviços e integrações oficiais verificáveis.

Consulte o [relatório técnico completo](https://github.com/heitgh/Moon-browser/blob/v0.5.0-demo.2/docs/audits/personalization-studio-v4-final-2026-08-30.md) e relate problemas em [GitHub Issues](https://github.com/heitgh/Moon-browser/issues).
