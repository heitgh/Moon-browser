# Suporte do Moon Browser

O Moon Browser ainda está em fase experimental. Para conseguir ajuda ou relatar um problema, use o canal adequado abaixo.

## Bugs

Abra uma issue usando o template **Bug report** e informe:

- versão ou origem do build;
- sistema operacional e arquitetura;
- passos mínimos para reproduzir;
- comportamento esperado e observado;
- capturas ou logs somente depois de remover informações sensíveis.

Issues: https://github.com/heitgh/Moon-browser/issues

## Ideias e melhorias

Use o template **Feature request**. Descreva primeiro o problema que deseja resolver e depois a solução sugerida. Isso ajuda a avaliar propostas sem transformar o roadmap em uma lista de recursos desconectados.

## Segurança

Não publique vulnerabilidades com detalhes exploráveis em uma issue pública. Consulte [SECURITY.md](SECURITY.md) antes de enviar qualquer relato relacionado a segurança, credenciais ou exposição de dados.

## Limites atuais

O Moon é experimental e não deve ser usado como único navegador para dados críticos. A disponibilidade de recursos varia entre a demo pública e o código atual da `main`; consulte o [README](README.md) para o estado mais recente documentado.

## Contribuições

Para alterações no código ou documentação, consulte [CONTRIBUTING.md](CONTRIBUTING.md).
